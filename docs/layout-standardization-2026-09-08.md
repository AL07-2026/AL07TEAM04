# 메뉴 화면 정렬 규격화

## 범위와 디자인 방향

- 작업 브랜치: leedongwook. 운영 화면과 서버는 변경하지 않는다.
- 기존 이어잡 브랜드 색상, 로고, 랜딩 콘텐츠를 유지하며 일반 회원 메뉴의 정렬을 통일한다.
- 디자인 강도: 배치 변화 1/10, 모션 1/10, 정보 밀도 4/10. 새 애니메이션이나 장식은 추가하지 않는다.
- 관리자 전용 콘솔은 별도 업무 화면으로 이번 일반 회원 메뉴 변경에 포함하지 않았다.

## 공통 규격

- 최대 폭 1152px, 좌우 여백 16px(640px 이상 32px).
- 헤더 높이 72px, 로고 높이 28px. 로고와 더보기는 동일한 상단 레일 양 끝에 배치.
- 본문 시작 간격 24px(640px 이상 32px), 하단 40px.
- 화면 폭 1024px 이상에서는 상단 중앙 메뉴, 그보다 좁으면 하단 메뉴. PC의 기기 모드 자체를 모바일로 바꾸지 않는다.
- 로그인, 가입 등의 입력 카드 내부는 읽기 편한 좁은 폭을 유지하되 바깥 헤더와 본문 틀은 공통으로 적용.

| Before | After | Why |
| --- | --- | --- |
| 랜딩 6xl, 회원 화면 7xl, 개별 화면 4xl~6xl 등 여러 폭 | site-rail 한 곳에서 폭과 좌우 여백 관리 | 메뉴 이동 시 좌우 기준선이 달라지는 현상 제거 |
| 뒤로가기 버튼이 로고 왼쪽에 삽입 | 본문 위로 이동 | 상세 화면에서도 로고 자리 유지 |
| 로그인·모바일·회원 화면의 헤더 3중 구현 | SiteHeader 및 단일 MobilePage 구조 | 높이·더보기·로고의 중복 구현 제거 |
| 개별 화면에서 공통 패딩과 폭 재정의 | 개별 화면은 내부 배치만 설정 | 이중 여백과 정렬 불일치 방지 |
| 작은 PC 창에서 주요 메뉴가 사라짐 | 좁은 폭에서 하단 메뉴 제공 | 화면 모드를 바꾸지 않고 탐색 유지 |

## 적용 화면

랜딩, 인재·기업 홈, 프로젝트 목록·상세·등록 모달의 바깥 화면, 제안 작성·완료·목록·상세, 인재·기업 내 정보, 경험 선택·인터뷰·카드, 커뮤니티, 프리미엄 기업 목록, 로그인·회원가입·역할 선택·기본정보.

내부 팝업의 가독성용 최대 폭은 유지한다. 프리미엄 등록, 첨부 업로드, DB 저장, 수집, 추천 점수 등의 비즈니스 로직은 변경하지 않는다.

## 검증과 제한

- 변경 전 공통 레일 및 뒤로가기 위치 테스트 4개 실패 확인 후 수정.
- 역할별 공통 레이아웃, 랜딩 4개 섹션, 상단·하단 메뉴의 비로그인 보호 경로 회귀 검증.
- 타입 검사·린트·55개 파일/531개 테스트·빌드 통과. 기존 번들 크기 경고와 테스트 환경의 scrollTo/navigation 안내는 남아 있다.
- 실제 브라우저 확인은 도구 승인 단계에서 작업공간 크레딧 부족으로 거절되었다. 다른 실행 수단으로 우회하지 않았다.
- 재개 후 브라우저 접근 복구. 로컬 랜딩·프로젝트·로그인 화면을 기본 데스크톱 및 390px에서 확인했고 더보기 이동과 비로그인 보호 메뉴 이동을 확인했다. 좁은 화면 가로 넘침 없음. 가입한 역할별 전체 화면과 모바일 키보드 검증은 아직 하지 않았다.
- 다음 확인: 320/390/768/1024/1440px, 비로그인/인재/기업, 긴 본문, 헤더 고정, 더보기 열기·닫기, 하단 메뉴와 지원 버튼, 입력 중 모바일 키보드.

## 별도 미해결 사항

이전 기업 등록 진단의 사진 업로드·재신청·저장 무결성 개선 및 Gmail 설정 누락에 따른 공통 API 배포 보류는 이번 레이아웃 작업으로 해결되지 않는다.
