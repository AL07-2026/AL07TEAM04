## 🚦 우선순위 및 처리 상태 기준

### 1. 우선순위 (Priority)
- 🚨 **긴급**: 화면이 멈추거나 동작하지 않는 버그, 사용자 경험을 심각하게 방해하는 문제 (즉시 수정)
- 🔶 **보통**: UI 레이아웃 미세 조정, 텍스트 가독성 개선, 일반적인 피드백 (다음 배포 시 반영)
- 🟢 **낮음**: 새로운 아이디어 제안, 추후 고도화 항목 (아이디어 보관)

### 2. 처리 상태 (Status)
- ⏳ **접수됨**: 피드백이 입력되어 AI 및 개발자가 확인 대기 중인 상태
- 🛠 **작업중**: 해당 수정 건에 대해 코딩 및 UI 개편 작업 진행 중인 상태
- ✅ **완료**: 코드 수정, 테스트 파이프라인 통과 및 미리보기 URL 배포가 완료된 상태
- ⏸️ **보류**: 디자인 재논의나 팀원 간 합의가 추가로 필요한 상태
