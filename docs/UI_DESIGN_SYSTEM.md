# 이어잡 UI 디자인 시스템

## 제품 방향

이어잡은 시니어 인재와 기업 담당자가 반복 사용하는 신뢰 중심 채용 제품이다. 기존의 웜 아이보리와 딥 에버그린 브랜드는 유지하고, 장식보다 정보 위계·가독성·예측 가능한 상호작용을 우선한다.

- 디자인 변주: 4/10 — 브랜드 개성은 유지하되 업무 화면은 익숙하게 구성한다.
- 모션 강도: 2/10 — 상태 변화만 짧게 전달하고 장식용 움직임은 피한다.
- 정보 밀도: 5/10 — 한 화면에서 비교가 가능하되 핵심 행동은 한 개만 강조한다.

## 의미 기반 토큰

| 역할           | 값        | 사용처                    |
| -------------- | --------- | ------------------------- |
| Background     | `#F7F3EA` | 앱 배경                   |
| Surface        | `#FFFFFF` | 카드, 폼, 대화상자        |
| Surface subtle | `#FAF7F2` | 보조 영역, 비활성 배경    |
| Text           | `#17212B` | 본문과 제목               |
| Primary        | `#173F3A` | 주요 행동, 포커스, 브랜드 |
| Accent         | `#B84734` | 선택 상태와 중요한 강조   |
| Secondary      | `#DDEBE7` | 안내와 보조 강조          |
| Muted text     | `#45556C` | 보조 설명                 |
| Border         | `#E0D9C8` | 구분선과 입력 테두리      |

Accent 색은 흰색 대비 5.26:1, 아이보리 대비 4.75:1을 확보한다. 본문 크기의 기존 코랄 `#F06B4F` 사용은 금지한다.

## 구성 원칙

- 페이지는 `제목 → 핵심 상태/필터 → 결과 → 주요 행동` 순서로 읽혀야 한다.
- 카드 모서리는 기본 12~16px, 그림자는 `shadow-sm` 수준으로 제한한다.
- 그라데이션은 핵심 정보 전달에 필요할 때만 사용한다. 버튼에는 단색 Primary를 사용한다.
- 주요 행동은 화면 또는 카드당 하나만 강하게 표현한다. 보조 행동은 외곽선이나 텍스트 버튼으로 낮춘다.
- 빈 상태, 로딩, 오류, 권한 없음 상태를 정상 화면과 같은 위계로 설계한다.
- 목록·필터 상태는 가능한 경우 URL과 동기화해 새로고침과 뒤로가기를 보존한다.

## 컴포넌트 기준

- 버튼과 입력 요소의 최소 높이는 44px이다.
- 아이콘만 있는 버튼에는 반드시 한국어 `aria-label`을 제공한다.
- 링크는 이동, 버튼은 동작에만 사용한다.
- 입력 필드는 보이는 라벨, `name`, 적절한 `type`, `autoComplete`를 가진다.
- 비동기 버튼은 `aria-busy`, 비활성 상태, 진행 문구를 함께 제공한다.
- 포커스는 딥 에버그린 3px 외곽선으로 항상 보이게 한다.
- `transition-all`은 사용하지 않고 실제로 변하는 속성만 지정한다.

## 콘텐츠와 반응형

- 버튼 문구는 “확인”보다 “채용공고 보기”, “정보 저장”처럼 결과를 설명한다.
- 긴 제목과 기업명은 줄바꿈을 허용하며 레이아웃 폭을 깨지 않게 한다.
- 모바일에서는 가로 스크롤을 만들지 않고 핵심 조작을 엄지 범위에 둔다.
- 고정 하단 조작은 `env(safe-area-inset-bottom)`을 고려한다.
- 이미지에는 의미 있는 대체 텍스트와 실제 `width`/`height`를 제공한다.

## 품질 점검

1. 데스크톱과 390px 모바일 폭에서 레이아웃을 확인한다.
2. 키보드만으로 모든 조작과 포커스 순서를 확인한다.
3. WCAG 2.1 AA 자동 검사를 실행하고 색 대비 오류를 0건으로 만든다.
4. `prefers-reduced-motion`에서 자동 전환과 장식 모션이 멈추는지 확인한다.
5. 로딩·오류·빈 결과·긴 한글/영문 텍스트 상태를 확인한다.
6. 구현 후 `npm run validate`와 Firebase 미리보기 채널 실화면을 모두 확인한다.
