# Context7 Live Documentation Skill

Context7 MCP 서버를 활용하여 AI 어시스턴트가 최신 버전의 라이브러리 공식 문서, API 스펙 및 코드 예제를 실시간으로 조회하고 반영하는 스킬입니다.

## 1. 사용 목적
- **환각(Hallucination) 방지**: LLM의 과거 학습 데이터에 의존하지 않고 현재 프로젝트의 실제 패키지 버전에 맞는 최신 API 사용법을 실시간으로 확인합니다.
- **최신 프레임워크 스펙 준수**:
  - React 19 (Server Actions, `use`, `useActionState`, `useOptimistic` 등)
  - Tailwind CSS v4 (새로운 `@theme`, CSS-first 구성)
  - Vite 8 & Vitest 4
  - Firebase 12 (Modular SDK v12, Firestore, Auth, Functions)
  - AssemblyAI, Lucide React, Express 5 등

## 2. 활용 방법
- 새로운 라이브러리 기능 도입 시 또는 버전 업그레이드 시 Context7 MCP 도구 또는 `use context7` 지침을 통해 공식 문서를 우선 참조합니다.
- 코드를 작성하기 전, 폐기(deprecated)되거나 시그니처가 변경된 메서드가 없는지 실시간 문서를 통해 검증합니다.
