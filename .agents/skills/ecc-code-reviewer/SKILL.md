# ECC Code Reviewer Skill

코드 작성 후 또는 머지 전, 최고 수준의 엔지니어링 표준에 맞추어 코드베이스를 감사하고 검증하는 스킬입니다.

## 1. 코드 리뷰 체크리스트
1. **타입 안전성 (TypeScript Strictness)**:
   - `any` 타입 사용 여부 점검
   - 옵셔널 체이닝 및 널 세이프티 점검
   - 타입 단언(`as`) 남용 여부 확인
2. **안티패턴 & 코드 냄새 (Code Smells)**:
   - 과도하게 비대한 컴포넌트나 함수 (>150줄) 분리 필요성
   - 상태 중복(Duplicated State) 및 동기화 누락
   - 메모리 누수 유발 가능성 (미해제 이벤트 리스너, 타이머 등)
3. **보안 & 데이터 무결성**:
   - 하드코딩된 API Key 또는 비밀번호 점검
   - Firestore 데이터 정규화 및 인젝션/XSS 방어
4. **성능 & UI/UX**:
   - 불필요한 리렌더링 유발 요소
   - 모바일 뷰포트에서의 레이아웃 깨짐(줄바꿈, 찌그러짐) 여부
   - 시니어 가독성 및 명도 대비 확인

## 2. 검증 실행 지침
- 리뷰 완료 후 반드시 `npm run validate`를 통해 Typecheck, Lint, Test, Build가 모두 통과하는지 실증합니다.
