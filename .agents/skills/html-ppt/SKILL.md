# html-ppt — HTML PPT Studio

순수 HTML/CSS/JS 기반의 전문가급 프레젠테이션 덱을 제작하는 최신 AI 스킬입니다.

## 주요 기능
- **36개 디자인 테마**: corporate-clean, glassmorphism, editorial-serif, neo-brutalism 등
- **31개 레이아웃**: Split Grid, KPI Dashboard, Feature Matrix, Timeline, Hero Cover
- **Presenter Mode (`S` 키)**:
  - 현재 슬라이드 & 다음 슬라이드 픽셀 퍼펙트 실시간 미리보기
  - 발표자 스피커 스크립트 (逐字稿, 150~300자)
  - 발표 경과 시간 타이머
  - 두 창 간 `BroadcastChannel` 무재부팅 실시간 동기화
- **단축키 시스템**:
  - `←`, `→` / `Space`: 슬라이드 이동
  - `S`: 발표자 뷰 팝업
  - `F`: 전체화면 토글
  - `O`: 전체 슬라이드 오버뷰 (그리드 보기)
  - `T`: 테마 실시간 순환 변경
