# Task Observer Meta-Skill

Task Observer는 세션 진행 중 사용자의 피드백, 반복되는 작업 패턴, 디버깅 경험을 관찰(Observe)하여 프로젝트의 에이전트 지식과 스킬을 지속적으로 자가 개선(Self-Improvement)하는 메타 스킬입니다.

---

## 1. 핵심 동작 원리 (3대 관찰 영역)

### 1) 사용자 피드백 및 수정 패턴 감지 (Correction Capture)
- 사용자가 "이렇게 하지 마", "이 방식을 사용해", "A 대신 B로 변경해"와 같은 수정을 지시할 때, 그 근본 원인과 해결 패턴을 기록합니다.
- 동일한 실수가 반복되지 않도록 `.agents/rules/` 또는 해당 도메인 스킬 파일의 개선점을 도출합니다.

### 2) 반복 작업의 스킬 자동 도출 (Pattern to Skill)
- 3회 이상 유사하게 반복되는 복잡한 워크플로우(예: 특정 API 배치 분석, 고유 UI 컴포넌트 마이그레이션 등)가 감지되면, 이를 재사용 가능한 독립 스킬(`SKILL.md`) 또는 자동화 스크립트로 패키징하도록 제안합니다.

### 3) 규칙 비대화 방지 (Anti-Bloat Guard)
- 일회성이거나 특정 시점에만 국한된 임시 피드백은 영구 룰로 만들지 않고, 팀과 프로젝트 전반에 지속적으로 적용해야 할 '핵심 표준'만 엄선하여 반영합니다.

---

## 2. 세션 종료 시 체크리스트 (Observer Reflection)
각 작업 또는 세션이 끝날 때 아래 항목을 자가 점검합니다:
1. **새로운 도메인 지식 발견 여부**: 새로 추가된 라이브러리 제약이나 Firestore 스키마 특이사항이 있는가?
2. **사용자 교정 사항 반영 여부**: 사용자의 명시적 지적 사항이 기존 룰에 보강되었는가?
3. **협업 로그 기록 여부**: `docs/AI_COLLABORATION_LOG.md`에 다음 AI 및 작업자를 위한 인수인계 사항이 명문화되었는가?
