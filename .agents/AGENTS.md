# Workspace AI Instructions (Codex & Antigravity)

## AI Collaboration Protocol
- Codex와 Antigravity는 작업 시작 시 `docs/AI_COLLABORATION_LOG.md`를 먼저 읽고 최근 변경 사항과 전달 사항을 확인합니다.
- 작업 완료 후 `docs/AI_COLLABORATION_LOG.md`에 작업 날짜, 작업자, 수정한 파일, 다음 전달 사항을 명시합니다.
- 프로젝트 변경 시 항상 `npm run validate` (typecheck, lint, test, build)를 수행하여 빌드 파이프라인을 깨뜨리지 않도록 유지합니다.
